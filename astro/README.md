# astro/

Astropods agent scaffold, generated by `ast init`. Self-contained — everything the agent build
needs lives in this directory.

**This is separate from the collection-maintenance work.** Nothing here reads or writes Postman
collections. See the repo root [`README.md`](../README.md) and
[`AGENTS.md`](../AGENTS.md) for that.

## Quick start

Run from **inside this directory**, not the repo root — the CLI resolves `astropods.yml` from
the current working directory. Verified with `ast spec validate` after the move.

```bash
cd astro
bun install

ast project configure   # set credentials and inputs (writes .env here)
ast project start       # start containers
ast project logs        # tail container logs
ast project stop        # stop containers
```

> The old root README said `ast dev`. That command does not exist in the CLI (checked against
> `ast/0.15.4`); local development is under `ast project`. Validate the manifest any time with
> `ast spec validate`.

`.env` (created by `ast configure`) is git-ignored and belongs here too.

## Configuration

`astropods.yml` defines:

- **Model** — self-hosted `ollama` provider running `llama3.1:8b`
- **Interfaces** — `messaging` with the `web` adapter (HTTP/SSE)

## messaging.postman_collection.json

Six requests against the endpoints `serve(agent)` exposes from `@astropods/adapter-mastra`:

```
GET   /health
POST  /api/conversations
POST  /api/conversations/{{conversationId}}/messages
GET   /api/conversations/{{conversationId}}/history
GET   /api/conversations/{{conversationId}}/stream
GET   /api/agent/config
```

> **Port is unverified.** The collection's `baseUrl` variable is `http://localhost:8080`, but the
> original README described the dev playground as `localhost:3000`, and `astropods.yml` pins
> neither. If requests are refused, check which port `ast dev` actually binds and fix `baseUrl`.

## Current state

The agent is a **stub**. `agent/index.ts` registers no tools — no Postman MCP, no `gh` — so it
cannot perform the maintenance work described in `AGENTS.md`. Making it do so would require
wiring in those tools and a considerably stronger model than `llama3.1:8b`.
